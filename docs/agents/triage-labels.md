# Triage labels

| 角色 | 标签 | 含义 |
| --- | --- | --- |
| 待评估 | `needs-triage` | 维护者需要评估 |
| 待补充信息 | `needs-info` | 等待报告者补充信息 |
| 可交给 Agent | `ready-for-agent` | 需求明确、授权充分且属于 AI 可实现范围 |
| 需要作者处理 | `ready-for-human` | 需要作者设计或实现 |
| 不处理 | `wontfix` | 决定不执行 |

作者保留的上层网络学习任务应归为 `ready-for-human`，不能仅因需求明确就标记为 `ready-for-agent`。
